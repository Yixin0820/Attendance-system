# 一键启动与排障

适用于 Windows 本机开发 / 演示，也适用于迁到云服务器前的本机验证。

启动脚本统一由 `scripts/start-all.mjs`（Node 实现）驱动，根目录下的 `.bat` 文件只做最简转发，
真正的启动逻辑、健康检查与日志都在这个脚本里。

---

## 一、四个入口

| 入口 | 作用 | 页面数据 |
|---|---|---|
| **`start-all.bat`** | 后端 API(8000) + 前端(4180)，自动开浏览器 | 真实数据库 |
| `start-backend.bat` | 只起后端，给前端 `npm run dev` 用 | — |
| `start.bat` | 只起前端，不连后端 | 本地演示数据 |
| `check-backend.bat` | 环境自检 + 真实联调验证，不启动长期服务 | — |

`start-all.bat` 启动后会保留一个命令行窗口，关掉窗口即停止全部服务。窗口里每一步都有中文进度提示，
失败会直接打印原因和 `backend/server.log` 末尾。

---

## 二、命令行用法

```bash
npm run check:backend    # 只体检，不启动服务
npm run verify:backend   # 启动后端 → 5 项联调 → 自动停止
npm run smoke            # 完整启动前后端 → 验证页面可访问 → 自动停止
npm run start:all        # 正式启动，保持运行
npm run start:backend    # 只起后端
npm run start:frontend   # 只起前端
```

`--no-browser` 可加在任意命令后，适合服务器 / 自动化环境：

```bash
node scripts/start-all.mjs --no-browser
```

**验收标准**：`npm run verify:backend` 的 5 项全部 `[PASS]`，
`npm run smoke` 显示端到端冒烟测试通过。两条都过，双击 `start-all.bat` 即可正常使用。

## 三、常见故障对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录页黄色「未连接后端，当前为本地演示数据」 | 后端没起来，或页面比后端先就绪 | 等 5 秒点登录页的「重新连接」；或跑 `check-backend.bat` |
| 提示 `[ERROR] Node.js not found` | 没装 Node 或没加 PATH | 装 Node 18+，重装时勾选 Add to PATH |
| 后端 40 秒未就绪 | 8000 被占用 / 依赖缺失 / Python 版本过低 | 看 `backend/server.log`；端口冲突用 `netstat -ano \| findstr :8000` 找占用进程 |
| 登录 500 `no such column` | 旧库结构落后 | 新版启动会自动补列；若仍报，删除 `backend/attendance.db` 后重启（**会清空演示数据**） |
| 所有业务接口 423「请先修改初始口令」 | 运维批量重置过口令，账号被标记首次改密 | 按登录页弹出的强制改密页设置新密码 |
| 登录 429「账号已临时锁定」 | 同一账号+IP 连续失败 5 次 | 等 10 分钟，或运维清空 `login_attempts` 表 |
| 上传附件 400「不支持的文件类型」 | 只放行 jpg/jpeg/png/pdf/docx | 换格式；改名伪装会被文件头校验拦下 |
| 端口 4180 打不开 | 构建产物缺失 | 启动器会自动 `vite build`；也可手动 `npm run build` |

日志位置：`backend/server.log`（每次启动覆盖写，含 uvicorn 完整堆栈）。

## 四、后端安全项说明

| 项 | 实现 |
|---|---|
| 登录失败限流 | `login_attempts` 表按「账号+IP」计数，5 次失败锁 10 分钟，成功后清零；支持 nginx `X-Forwarded-For` |
| 首次登录强制改密 | 被标记账号除登录/改密/me 外全部返回 423；前端弹不可关闭的改密页，成功后用新口令重新登录 |
| 口令策略 | 最少 8 位、拒绝常见弱口令与纯重复字符、不能与原口令相同 |
| 批量下发随机口令 | `POST /api/ops/accounts/reset-random`（仅 ops），一次性返回明文清单，全部标记须改密 |
| 上传白名单 | 扩展名白名单 + 文件头魔数 + docx 结构校验；MIME 由服务端判定，不信任客户端 |
| 旧库自愈 | SQLite 启动时检测并补齐缺失列 |

> ⚠️ `reset-random` 会**改写所有启用账号的口令**，且明文只在响应里出现一次。
> 执行前务必先备份数据库，立刻导出清单并线下分发；详见 `docs/账号清单.md`。
