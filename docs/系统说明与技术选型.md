# 晚自习考勤管理系统 · 架构说明与技术选型

## 一、项目定位

面向高校院系晚自习考勤的轻量级全栈系统，覆盖「应到变更留痕 / 七轮四人查考勤 / 跨周调班 / 玩手机公示 / 检讨附件 / A4 纵版 Excel 导出」等业务环节。

系统包含四个角色端：

- **班委端**：上报考勤、管理请假与假条、查看本班玩手机公示
- **查勤端**：查班、查手机、假条核查、检讨专区、排班与调班
- **管理端**：总览、待办、排班、历史、教室
- **运维端**：账号、口令、操作日志、考勤排次锚点

业务闭环：上报 → 核查 → 问题标记 → 检讨上传 → 汇总导出 → 历史查询 → 调班协商。

## 二、关键业务规则

- **应到人数变更留痕**：修改必须填写原因，记录修改人、时间、修改前后值；管理端可「确认已阅」（仅留痕，不审批、不回退人数）。
- **当日玩手机公示**：无人被查到时显示「平安夜」。
- **查考勤按「次」续排**：以锚点日期为起点，每遇到一个有晚自习的日子推进一轮，共七轮分组循环；无晚自习的日子不占轮次，节假日停课不打乱顺序。查班、查手机仍支持本周/下周与跨周调班，考勤岗位固定按次轮转。
- **跨周调班**：支持冲突校验、双向互换、拒绝不改表。
- **导出 Excel**：真正生成 `.xlsx`，A4 纵版、重复标题、页脚页码，含美化表与纯黑白表两种风格。

## 三、架构

```
浏览器（React + TypeScript）
   ↓ HTTPS / JSON
FastAPI 单体应用
   ├─ 路由：auth / meta / roster / attendance / swap / files / ops
   └─ 服务层：排班校验、考勤排次、应到人数、教室规则
   ↓
PostgreSQL（生产） / SQLite（开发）
   + 本地磁盘附件（可替换为对象存储）
Nginx 反向代理 + HTTPS，定时备份，操作日志
```

前端状态集中在 `src/store.tsx`；业务规则抽成纯函数（`src/lib/roster.ts`、`src/lib/exportAttendance.ts`），可在 Node 环境下直接单元测试。后端复用同一套调班校验逻辑（`backend/app/services/roster.py`），保证前后端规则一致。

## 四、技术选型

### 前端：React + TypeScript

现有业务逻辑已用 React 完整实现并验证通过。重写成 Vue 等于把已验证的业务逻辑重新实现一遍，投入大、收益小。两者性能对本项目（几十人使用、页面简单）均不构成瓶颈，因此保持不变。

### 后端：FastAPI（Python）

选择 Python + FastAPI，主要考虑：

- 项目规模小（日活几十到几百、QPS 个位数），开发效率与可维护性优先于极限运行性能。
- 学生团队维护，Python 的学习与交接成本最低。
- 业务包含较多办公文档与数据处理（xlsx 导出、图片处理、统计报表），Python 生态最顺手。
- FastAPI 自带 OpenAPI 文档、原生异步、基于类型注解的参数校验，前后端协作成本低。

如后续需要接入模型能力（假条识别、异常考勤提醒），Python 也是成本最低的选择。

### 数据库：PostgreSQL

考勤系统有两类查询会越来越复杂：跨班级 / 跨日期的统计汇总，以及「某班某人在某段时间的全部记录」。PostgreSQL 在复杂查询、约束校验、JSONB 扩展上更稳。项目数据量不大，MySQL 同样可以运行，但选型带来的收益差距，远小于「是否做了后端校验与备份」这一事实。开发期使用 SQLite 零安装，生产切换到 PostgreSQL 仅需改一个环境变量。

### 部署：单体 + 模块化

不采用微服务。一个学院、几百人、每天几次操作，微服务所解决的多团队并行开发与独立伸缩问题在此都不存在；其引入的服务发现、网关、链路追踪、分布式事务只会加重运维负担。目标架构为单体应用按模块分包，待确实需要独立伸缩时再按模块拆出。

## 五、目录结构

```
.
├── src/                前端（React + TS）
│   ├── data.ts         业务基础数据（校/院/班/教室/干事/排班）
│   ├── components/     页面与组件
│   ├── lib/            导出、API、排次、调班等逻辑
│   └── store.tsx       全局状态容器
├── backend/            FastAPI 后端
│   ├── app/            路由、模型、服务、配置
│   ├── migrations/     Alembic 迁移脚本
│   ├── seed/           种子数据（由 src/data.ts 生成）
│   └── tests/          后端测试
├── scripts/            一键启动 / 种子导出
├── deploy/             Docker / nginx / 备份脚本
└── docs/               部署指南、缺口清单等
```
